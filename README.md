# AI Odyssey

Create a premium, modern, futuristic 3D personal portfolio website for a B.Tech Computer Science Engineering (CSE) student specializing in Artificial Intelligence & Machine Learning (AI/ML) at JECRC University – Alwar NCR Campus, Rajasthan, India.

The website should look like a professional developer/AI engineer portfolio rather than a basic student website.

🎨 DESIGN & COLOR THEME

Use a trending 2026 futuristic tech aesthetic.

Primary colors:

Deep black / near-black background

Electric blue

Neon cyan

Purple/violet accents

Subtle white/gray text

Use gradients such as:

Blue → Cyan

Purple → Blue

Cyan → Violet

Add glassmorphism, soft glowing borders, subtle shadows, gradient text, animated backgrounds, and smooth transitions.

The overall design should feel:
Futuristic + Premium + Minimal + Professional + AI/Technology focused.

🌐 HERO SECTION

Create a stunning full-screen hero section.

Display:

Hi, I'm [YAMAN PRAJAPAT]👋

B.Tech CSE (AI & ML) Student

JECRC University – Alwar NCR Campus

Add a short introduction:

"Passionate Computer Science student exploring Artificial Intelligence, Machine Learning, Python, Web Development and emerging technologies."

Add two prominent buttons:

Explore My Journey
View My Projects

Include a 3D animated object related to AI/programming, such as:

A floating 3D holographic AI brain

Rotating 3D neural network

Floating code symbols

Glowing particles

Interactive 3D geometric objects

The 3D object should react subtly to mouse movement.

✨ 3D EFFECTS

Use Three.js / React Three Fiber wherever appropriate.

Include:

Interactive 3D AI brain or neural network

Floating particles

3D geometric shapes

Mouse-following effects

Depth/parallax effects

Floating cards

Smooth camera movement

Interactive hover animations

Glowing neon objects

Keep the 3D effects optimized so the website remains fast and responsive.

🌟 FINAL VISUAL STYLE

AI Engineer Portfolio + Futuristic 3D Website + Premium Developer Portfolio + Modern Student Identity

Other students

Developers

Avoid generic templates.

Make the design original, polished, futuristic and visually impressive.

Add subtle details such as glowing gradients, animated grid backgrounds, floating particles, holographic cards and interactive 3D elements.

The website should communicate:

"A young CSE student building his journey toward AI & technology."

Make every section editable so the student can later add real projects, certificates, achievements, GitHub repositories and social links.
